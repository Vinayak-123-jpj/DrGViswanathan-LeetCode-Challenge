Day 49
Problem

Night at the Museum

Platform

Codeforces

Problem Number

731A

Difficulty

Easy

Approach
Start from the character 'a'.
Traverse the string one character at a time.
Calculate the clockwise and counter-clockwise distance between the current character and the next character.
Add the minimum of these two distances to the answer.
Update the current character.
Time Complexity

O(n)

Space Complexity

O(1)

Key Learning

Practiced strings, character manipulation, ASCII values, and circular distance calculations in C++.
