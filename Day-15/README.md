# Day 15

## Problem
Boy or Girl (236A)

## Platform
Codeforces

## Difficulty
800

## Approach
- Read the input username.
- Store every character in a `set<char>` to keep only unique characters.
- Check the number of distinct characters:
  - If even, print `CHAT WITH HER!`
  - Otherwise, print `IGNORE HIM!`

## Time Complexity
O(n log n)

## Space Complexity
O(n)

## Concepts Used
- Strings
- STL Set
- Unique Elements
- Conditional Statements
