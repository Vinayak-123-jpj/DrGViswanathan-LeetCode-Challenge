# Day 12

## Problem
Petya and Strings (112A)

## Platform
Codeforces

## Difficulty
800

## Approach
- Read two strings.
- Convert both strings to lowercase.
- Compare them lexicographically.
- Print:
  - -1 if first string is smaller.
  - 1 if first string is greater.
  - 0 if both are equal.

## Time Complexity
O(n)

## Space Complexity
O(1)

✅ Accepted
