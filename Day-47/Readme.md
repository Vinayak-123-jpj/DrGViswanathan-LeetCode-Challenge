Problem

Cheap Travel

Platform

Codeforces

Approach
Calculate the cost of buying all rides individually.
Calculate the cost using special tickets for groups of m rides.
For the remaining rides, choose the cheaper option between individual rides and one special ticket.
Take the minimum possible cost.
Time Complexity

O(1)

Space Complexity

O(1)
