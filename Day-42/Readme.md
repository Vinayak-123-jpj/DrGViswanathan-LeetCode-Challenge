Day 42
Problem

Young Physicist

Platform

Codeforces

Problem Number

69A

Difficulty

Easy

Approach
Initialize the sums of the x, y, and z components to 0.
Read all the force vectors.
Add each vector's components to their respective sums.
If all three sums are 0, the forces are balanced.
Otherwise, the body is not in equilibrium.
Time Complexity

O(n)

Space Complexity

O(1)

Key Learning

Practiced vectors, loops, summation, and condition checking in C++.
