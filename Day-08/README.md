# Day 8

## Problem
Way Too Long Words (71A)

## Platform
Codeforces

## Difficulty
800

## Approach
- Read the number of test cases.
- For each word:
  - If its length is less than or equal to 10, print it directly.
  - Otherwise, print the first character, followed by (length - 2), and then the last character.

## Time Complexity
O(n)

## Space Complexity
O(1)

## Status
✅ Accepted
