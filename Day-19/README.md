# Day 19

## Problem
Domino Piling (50A)

## Platform
Codeforces

## Difficulty
800

## Approach
- Read the dimensions `m` and `n`.
- Compute the total number of cells (`m × n`).
- Since one domino occupies two cells, the maximum number of dominoes is `(m × n) / 2`.
- Print the result.

## Time Complexity
O(1)

## Space Complexity
O(1)

## Concepts Used
- Mathematics
- Integer Division
- Basic Arithmetic
