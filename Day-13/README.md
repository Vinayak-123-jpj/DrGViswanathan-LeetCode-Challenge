# Day 13

## Problem
Helpful Maths (339A)

## Platform
Codeforces

## Difficulty
800

## Approach
- Read the input string.
- Store all digits in a vector.
- Sort the vector in ascending order.
- Print the numbers with '+' between consecutive elements.

## Time Complexity
O(n log n)

## Space Complexity
O(n)

## Concepts Used
- Strings
- Vectors
- STL sort()
- Character Processing
