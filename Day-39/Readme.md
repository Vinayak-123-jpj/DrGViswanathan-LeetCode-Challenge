Day 39
Problem

I_love_%username%

Platform

Codeforces

Difficulty

Easy

Approach
Read the number of scores.
Take the first score as both the minimum and maximum.
Traverse the remaining scores.
If a score is smaller than the current minimum, increment the count.
If a score is greater than the current maximum, increment the count.
Update the minimum or maximum accordingly.
Print the total number of amazing performances.
Time Complexity

O(n)

Space Complexity

O(1)
