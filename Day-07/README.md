# Day 7

## Problem
Watermelon (4A)

## Platform
Codeforces

## Difficulty
800

## Approach
- Read the weight of the watermelon.
- Check if the weight is even.
- Ensure the weight is greater than 2.
- If both conditions are true, print "YES"; otherwise, print "NO".

## Time Complexity
O(1)

## Space Complexity
O(1)
