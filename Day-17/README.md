# Day 17

## Problem
Stones on the Table (266A)

## Platform
Codeforces

## Difficulty
800

## Approach
- Read the number of stones and the string.
- Traverse the string from the second character.
- Compare each character with its previous character.
- If both are the same, increment the removal counter.
- Print the total number of removals.

## Time Complexity
O(n)

## Space Complexity
O(1)

## Concepts Used
- Strings
- Linear Traversal
- Adjacent Element Comparison
- Counting
