# Day 20

## Problem
Translation (41A)

## Platform
Codeforces

## Difficulty
800

## Approach
- Read the strings `s` and `t`.
- Reverse string `s`.
- Compare the reversed `s` with `t`.
- If they are equal, print `YES`; otherwise, print `NO`.

## Time Complexity
O(n)

## Space Complexity
O(1)

## Concepts Used
- Strings
- String Reversal
- String Comparison
