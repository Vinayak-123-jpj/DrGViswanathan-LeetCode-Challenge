# Day 27

## Problem

Drinks (200B)

## Platform

Codeforces

## Difficulty

800

## Approach

* Read the number of drinks.
* Store the sum of all juice percentages.
* Calculate the average using `sum / n`.
* Use `double` because the answer can contain decimal values.
* Print the average.

## Example

Input:

```text
3
50 50 100
```

Output:

```text
66.6667
```

## Time Complexity

O(n)

## Space Complexity

O(1)

## Concepts Used

* Arrays/Input
* Average
* Floating-point numbers
* `double`
* Loops
