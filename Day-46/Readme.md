Day 46
Problem

Sereja and Dima

Platform

Codeforces

Problem Number

381A

Difficulty

Easy

Approach
Use two pointers: l at the beginning and r at the end of the array.
Compare a[l] and a[r].
The current player chooses the larger value.
Move the corresponding pointer inward.
Alternate turns between Sereja and Dima.
Continue until all elements are chosen.
Time Complexity

O(n)

Space Complexity

O(n)

Key Learning

Practiced two pointers, greedy approach, arrays, and simulation in C++.
