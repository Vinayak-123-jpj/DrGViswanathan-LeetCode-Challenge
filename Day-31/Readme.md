Day 31
Problem

Magnets

Platform

Codeforces

Difficulty

Easy

Approach
Read the number of magnets.
Store the first magnet as prev.
For every next magnet, compare it with the previous magnet.
If the current magnet is different, start a new group.
Update prev after every magnet.
Print the total number of groups.
Time Complexity

O(n)

Space Complexity

O(1)
