# Day 9

## Problem
Team (231A)

## Platform
Codeforces

## Difficulty
800

## Approach
- Read the number of problems.
- For each problem, read three integers (0 or 1).
- Count how many teammates are sure about the solution.
- If the count is at least 2, increment the answer.
- Print the final answer.

## Time Complexity
O(n)

## Space Complexity
O(1)
