# Day 10

## Problem
Next Round (158A)

## Platform
Codeforces

## Difficulty

## Approach
- Read the number of participants and the qualifying position.
- Store all scores in an array.
- Find the score of the k-th participant.
- Count participants whose score is greater than or equal to the qualifying score and greater than zero.
- Print the final count.

## Time Complexity
O(n)

## Space Complexity
