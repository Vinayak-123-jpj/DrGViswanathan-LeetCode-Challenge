# Day 18

## Problem
Bit++ (282A)

## Platform
Codeforces

## Difficulty
800

## Approach
- Initialize the variable `x` to 0.
- Read each operation as a string.
- Check whether the operation contains `'+'`.
- If yes, increment `x`; otherwise, decrement `x`.
- Print the final value.

## Time Complexity
O(n)

## Space Complexity
O(1)

## Concepts Used
- Strings
- Conditional Statements
- Linear Traversal
