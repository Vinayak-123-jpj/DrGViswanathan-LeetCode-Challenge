# Day 6

## Problem
Valid Parentheses

## Platform
LeetCode

## Difficulty
Easy

## Approach
- Used a stack to store opening brackets.
- Traversed the string character by character.
- Pushed opening brackets onto the stack.
- Compared closing brackets with the top of the stack.
- Returned false if a mismatch occurred.
- Returned true only if the stack was empty at the end.

## Time Complexity
O(n)

## Space Complexity
O(n)
