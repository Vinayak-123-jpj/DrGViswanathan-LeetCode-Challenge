# Day 5

## Problem
Roman to Integer

## Platform
LeetCode

## Difficulty
Easy

## Approach
- Created a helper function to map Roman symbols to integer values.
- Traversed the string once.
- Compared the current symbol with the next symbol.
- If the current value was smaller than the next, subtracted it.
- Otherwise, added it to the final answer.

## Time Complexity
O(n)

## Space Complexity
O(1)
