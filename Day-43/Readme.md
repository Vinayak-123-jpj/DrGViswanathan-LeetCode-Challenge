Problem

Calculating Function

Platform

Codeforces

Problem Number

486A

Difficulty

Easy

Approach
Observe the alternating pattern of the function.
If n is even, the result is n / 2.
If n is odd, the result is -(n + 1) / 2.
Use the formula directly instead of calculating each term.
Time Complexity

O(1)

Space Complexity

O(1)

Key Learning
