Problem Number

Difficulty

Easy

Approach
Read the number of people and the available quantities of drink, limes, and salt.
Calculate how many toasts can be made using the available drink.
Calculate how many toasts can be made using the available lime slices.
Calculate how many toasts can be made using the available salt.
Take the minimum of these three values.
Divide the result by the number of people to get the number of toasts each person can make.
