Day 44
Problem

CAPS LOCK

Platform

Codeforces

Problem Number

131A

Difficulty

Easy

Approach
Traverse the string and check the capitalization of each character.
If all characters are uppercase, toggle the case of the entire string.
If only the first character is lowercase and the remaining characters are uppercase, toggle the case.
Otherwise, keep the string unchanged.
Time Complexity

O(n)

Space Complexity

O(1)

Key Learning

Practiced strings, character case conversion, loops, and conditional logic in C++.
