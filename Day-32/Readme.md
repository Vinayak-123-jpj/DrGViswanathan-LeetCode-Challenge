Day 31
Problem

Nearly Lucky Number

Platform

Codeforces

Problem Number

110A

Difficulty

Easy

Approach
Read the given number as a string.
Traverse each digit of the number.
Count the digits that are 4 or 7.
Check whether the count is itself a lucky number (4 or 7).
If yes, print YES; otherwise, print NO.
Time Complexity

O(n)

Space Complexity

O(1)

Status

Accepted ✅
