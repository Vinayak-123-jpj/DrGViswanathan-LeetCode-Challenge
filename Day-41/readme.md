Day 41
Problem

George and Accommodation

Platform

Codeforces

Problem Number

467A

Difficulty

Easy

Approach
Read the number of rooms.
For each room, read the current number of people p and the room capacity q.
Calculate the available space using q - p.
If at least 2 spaces are available, increment the count.
Print the total number of rooms available.
Time Complexity

O(n)

Space Complexity

O(1)

Status

Accepted ✅
