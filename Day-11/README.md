# Day 11

## Problem
String Task (118A)

## Platform
Codeforces

## Difficulty
800

## Approach
- Read the input string.
- Traverse each character.
- Convert it to lowercase.
- Skip vowels (A, O, Y, E, U, I).
- Print a dot followed by every remaining character.

## Time Complexity
O(n)

## Space Complexity
O(1)

✅ Accepted
