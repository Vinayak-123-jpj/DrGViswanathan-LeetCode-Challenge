Day 48
Problem

Arrival of the General

Platform

Codeforces

Problem Number

486A

Difficulty

Easy

Approach
Find the position of the first tallest soldier.
Find the position of the last shortest soldier.
Calculate the swaps required to move the tallest soldier to the front.
Calculate the swaps required to move the shortest soldier to the back.
If the tallest soldier is after the shortest soldier, subtract 1 because one swap overlaps.
Time Complexity

O(n)

Space Complexity

O(n)

Key Learning

Practiced arrays, searching, indexing, greedy thinking, and swap calculations in C++.
