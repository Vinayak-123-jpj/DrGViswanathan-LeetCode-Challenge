# 🚀 Dr. G. Viswanathan 50-Day Coding Challenge

> **50 Days • 50 Problems • Consistency • Problem Solving • C++**

This repository contains my journey through the **Dr. G. Viswanathan 50-Day Coding Challenge**, where I solved one programming problem every day to build consistency and strengthen my problem-solving skills.

The challenge started with basic programming and gradually progressed into problems involving **strings, arrays, mathematics, greedy approaches, simulation, two pointers, and competitive programming fundamentals**.

## 🎯 Challenge Goals

- 💻 Solve at least one problem every day
- 🧠 Improve logical and problem-solving skills
- 📚 Strengthen C++ fundamentals
- ⚡ Practice competitive programming
- 🔥 Build consistency through daily coding
- 📈 Gradually increase problem-solving difficulty
